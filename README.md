# Agent3D

Agent3D is an immersive React and Three.js prototype for managing geometry-based AI agents.

The interface centers on agents as 3D bodies placed on a stepped studio stand. Focusing an agent reveals lightweight glass-style controls for task dispatch, task history, and operational details. Backend behavior is mocked through a scripted frontend runtime.

## Features

- Geometry-driven agent bodies with state-based lighting and motion
- Parameterized visual semantics for geometry, material, state, and motion
- Stage layout system for placing agents on tiered stands
- Mock command runtime for task assignment, approval, and execution states
- Lightweight floating UI for focused agent control
