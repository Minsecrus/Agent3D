为了实现 **“方案 1：【全息账本/公文包】隐喻”**，我们需要在原有的 Agent 参数文档基础上，新增一套专门用来控制 **“3D 智子球 ⇄ 2D 全息投影账本”** 联动与渲染的参数。

这套参数将负责控制：**投影的视觉动效、人机交互的物理联动、以及数据的状态同步**。

以下是这一部分的高级参数文档定义：

---

### 一、 投影视觉控制参数 (Holographic Projection Visual Parameters)

*这组参数直接传递给 WebGL 渲染管线（如 Three.js）和 CSS 3D 引擎，负责控制“全息光束”和“悬浮账本面板”的出现、倾角及视觉质感。*

| 参数字段                | 类型         | 推荐取值/范围                               | 说明及视觉表现                                                                                       |
| :---------------------- | :----------- | :------------------------------------------ | :--------------------------------------------------------------------------------------------------- |
| `projection_state`      | Enum         | `CLOSED` / `OPENING` / `OPENED` / `CLOSING` | **投影状态机**。控制投影光束的展开与收起动效（驱动 GSAP 动画）。                                     |
| `projection_tilt_angle` | Float        | `-15.0` ~ `15.0` (度)                       | **账本透视倾角**。让 2D 表格在 3D 空间中微微倾斜（如 3D CSS transform），增强全息立体感。            |
| `beam_intensity`        | Float        | `0.0` (无) ~ `1.0` (强光)                   | **全息光源光束强度**。控制从智子球底部射向表格顶部的体积光（Volumetric Light）亮度。                 |
| `beam_color`            | String (Hex) | 继承 Agent 的 `base_color`                  | **投影光束颜色**。保证智子球与它投射出的账本在视觉上色彩统一。                                       |
| `ledger_opacity`        | Float        | `0.1` ~ `0.9`                               | **账本面板透明度**。通常设置为 `0.75`，呈现出科技感极强的半透明磨砂玻璃质感。                        |
| `scan_line_frequency`   | Float        | `0.0` (无) ~ `5.0` (高频)                   | **全息扫频线噪点强度**。在账本表面模拟微弱的、向上滚动的全息扫描线和轻微像素抖动（Hologram Noise）。 |

---

### 二、 交互物理联动参数 (Interactive Mapping Parameters)

*当用户在 2D 表格中操作时，3D 智子球必须做出实时的物理反馈（反之亦然），这组参数负责维护这种“主客体联动”。*

#### 1. 焦点与引导联动

* `focused_row_id` (当前焦点行 ID)：
  * **类型**：String (UUID) / `null`。
  * **用途**：当 Agent 提示“这行数据有异常”时，对应的数据行会高亮。同时，3D 智子球会产生微小的倾斜，朝向该行数据的方向。
* `sophon_aim_target` (智子瞄准坐标)：
  * **类型**：Vector3 `{ x, y, z }`。
  * **用途**：计算当前被 hover（悬停）的数据行在 3D 空间中的坐标，让智子球射出的“扫描激光”能精准打在用户鼠标悬停的那一行数据上。

#### 2. 行为动作反馈联动（`visual_feedback_trigger`）

定义人类操作数据时，3D 智子球的**情绪扰动反馈**：

* `on_cell_double_click` (双击编辑数据)：
  * **智子反馈**：智子球表面产生轻微的高频震颤（`noise_scale` 短暂飙升），代表“正在同步记录人类的修改”。
* `on_row_delete` (删除一行数据)：
  * **智子反馈**：全息光束闪烁一下，智子球微微向后退缩 10 像素（Z轴位移），随后恢复，表现出“对数据缺失的感知”。
* `on_submit_all` (一键提交/放行账本)：
  * **智子反馈**：全息光束猛烈汇聚，账本表格迅速缩小并呈粒子状“吸入”智子球底部，智子球进入 `EXECUTING`（高速自转）状态。

---

### 三、 数据同步与决策参数 (Data Sync & State Parameters)

*这组参数在业务层连接了原始数据库、Agent 的认知、以及用户的操作状态。*

| 参数字段             | 类型           | 说明及取值范围                                                          | 对应业务逻辑                                                                           |
| :------------------- | :------------- | :---------------------------------------------------------------------- | :------------------------------------------------------------------------------------- |
| `ledger_data_source` | String (URL)   | 账本所绑定的底层数据库接口。                                            | 决定表格里渲染的是什么数据。                                                           |
| `ledger_schema`      | Object         | 账本表头及字段定义（列名、数据类型、是否可编辑）。                      | 决定表格的结构（Columns config）。                                                     |
| `dirty_rows`         | Array [Object] | 暂存用户修改了、但尚未点击“提交保存”或“交由 Agent 执行”的数据行。       | 维护本地脏数据，防止未保存丢失。                                                       |
| `audit_rules`        | Array [String] | 该账本需要遵循的规则库（例如：`["price > 1000", "status != error"]`）。 | Agent 会根据这些规则在账本中自动标红、划重点。                                         |
| `lock_state`         | Boolean        | `true` (锁定) / `false` (解锁)。                                        | 当 Agent 正在写入数据，或正在向数据库大批量提报时，账本处于锁定状态，2D 表格置灰只读。 |

---

### 四、 参数联动工作流示例：用户修改账本数据

为了让你更清楚这套参数如何在实际代码中运行，我们模拟一个**“用户修改价格数据”**的流转过程：

```json
// 1. 初始状态：智子正在静止悬浮，投射出账本
agent_state = {
  "id": "agent_finance_01",
  "current_state": "IDLE",
  "projection_state": "OPENED"
}

// 2. 交互发生：用户双击修改了 ID 为 #1092 的订单金额
// 触发前端事件：
ledger_state.dirty_rows.push({ "row_id": "1092", "field": "amount", "old_value": 50, "new_value": 500 });

// 3. 联动激活：
// a) 智子视觉参数发生扰动：
agent_state.noise_scale = 1.2; // 智子球表面开始泛起波纹，表现“正在思考和记录”
agent_state.core_pulse_hz = 4.0; // 内核脉冲变快

// b) 智子计算并瞄准：
agent_state.sophon_aim_target = getRowWebGLPosition("1092"); // 智子球微微偏转，投射出一道激光束直指第 1092 行

// 4. 用户点击【保存并交由 Agent 确认】：
// a) 表格锁定：
ledger_state.lock_state = true;
// b) 智子状态切换为执行：
agent_state.current_state = "EXECUTING"; // 智子球开始高速旋转，光束变亮 (beam_intensity = 1.0)
// c) 写入成功后恢复：
agent_state.current_state = "IDLE";
ledger_state.lock_state = false;
ledger_state.dirty_rows = [];
```

### 总结

通过引入这套 **“全息投影控制参数”**，3D 的“智子（主）”和 2D 的“账本（宾）”就拥有了强有力的语义纽带。3D 不再只是好看的背景，而是成为了 2D 数据的**投影源、指示器和状态监控器**。这套文档可以直接交由前端（实现 WebGL 动效和表格联动）与后端（实现数据状态同步）协同开发。
